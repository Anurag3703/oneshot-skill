# Compare Snowflake, BigQuery, and Databricks for Large-Scale Order Analytics

## Objective
Produce a decision-ready comparison of Snowflake, BigQuery, and Databricks for analyzing billions of orders, ending with a recommendation under explicit criteria.

## Constraints
- Compare all three on the same dimensions
- Prefer authoritative primary sources
- State uncertainty explicitly

## Execution Steps
1. Restate decision criteria: scale/storage, query performance, cost model, architecture/ecosystem, operational complexity, concurrency/latency for analytics.
2. Gather current facts for each platform on those criteria.
3. Compare side-by-side; avoid one-sided claims.
4. Note assumptions (query patterns, freshness, team skills).
5. Recommend a primary option with tradeoffs and when another option wins.

## Expected Output
- Structured comparison (table or equivalent sections)
- Clear recommendation and next implementation step

## Validation
- All three platforms covered on the same criteria
- Claims tied to named source types
- Recommendation follows from the comparison

## Definition of Done
Comparison covers the listed criteria with evidence and a justified recommendation is provided.
